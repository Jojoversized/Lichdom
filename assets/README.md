# Assets

Generated by `npm run assets` (see `tools/assets/`). Everything here is deterministic output of
the painters/synth — edit the generators rather than the files, then regenerate and commit.

- `sprites/units` — recruitable undead and the Lich
- `sprites/enemies` — mortal crusaders and siege engines
- `sprites/bosses` — boss characters
- `sprites/summons` — Soul Well summons
- `sprites/towers` — 3 tiers × 4 animation frames per tower
- `sprites/fortifications` — walls, barricades, traps
- `sprites/environment` — keeps (one per fortress), the Soul Well, `props/`
- `sprites/effects` — shadows and other effect sprites
- `ui/icons` — 16×16 interface icons
- `audio/sfx` — synthesized sound effects; `audio/music` — reserved for composed tracks
- `data/` — `manifest.json` (sheet metadata), `palette.json`, `sfx.json`
